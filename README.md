# Замер скорости интернета

Консольный скрипт на Node.js для измерения скорости скачивания данных.

Скрипт выполняет 10 последовательных HTTP-запросов к указанному адресу, каждый раз дожидаясь полного получения ответа, и выводит:

- среднее время запроса;
- общий объём скачанных данных;
- скорость скачивания.

## Запуск

Для запуска необходимо установить Node.js.

Выполните команду:

```bash
node index.js <URL>
```

Пример:

```bash
node index.js https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

## Единицы измерения

- Время — секунды (с).
- Объём — мегабайты (МБ, 1 МБ = 1 000 000 байт).
- Скорость — мегабиты в секунду (Мбит/с).

## Формула расчёта скорости

Скорость рассчитывается по формуле:

```text
Скорость = (всего_байт × 8) / суммарное_время / 1 000 000
```

Суммарное время — это время выполнения всех запросов без дополнительных пауз между ними.

## Обработка ошибок

Если запрос не удался (неверный адрес, HTTP-ошибка или превышение таймаута в 30 секунд), скрипт:

- выводит причину ошибки в stderr;
- завершает выполнение с кодом 1.
